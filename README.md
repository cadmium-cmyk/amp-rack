# Amp Rack - Audio Effects Processor for Android

Amp Rack is an Open Source Guitar & Audio Effects Processor and Rack for Android, rewritten in modern Kotlin with Jetpack Compose and Material 3 design.

## Features

- **Audio Effects Rack**:
  - Live effect chain supporting unlimited pedals in any order
  - Reordering (Move Up / Down), individual bypass footswitches, and parameter tuning
  - Catalogue of 200+ LADSPA / LV2 audio plugins (Distortions, Overdrives, Tube Amplifiers, Speaker Cabinets, Delays, Reverbs, Stereo Chorus, Flangers, Phasers, Graphic EQs, Compressors, Noise Gates, and more)
  - Searchable effect drawer with category filtering

- **Tone Presets**:
  - Factory presets for ready-made tones (British Crunch, Heavy Metal Lead, Texas Blues Clean, Dreamy Ambient, Funk Groove)
  - Save, manage, and delete custom user presets

- **Drum Machine & Backing Tracks**:
  - 8-step multi-track drum sequencer (Kick, Snare, Hi-Hat Closed/Open, Toms, Cowbell, Crash)
  - Dynamic tempo control (60 - 240 BPM) with preset rhythm patterns (Rock Standard, Funk Groove, Blues Shuffle)
  - Integrated guitar backing track loop player for scale practice and solos

- **Chromatic Guitar Tuner**:
  - Accurate pitch detection and string selectors (E2, A2, D3, G3, B3, E4)
  - High-precision cents deviation gauge with in-tune status feedback
  - Audio reference pitch test tone generator

- **Studio Audio Recorder**:
  - Quick take recording with real-time digital timer and animated waveform display
  - Support for WAV 24-bit, MP3 320k, and Opus HD formats
  - Recorded take management and playback

- **Hardware Connection Guide**:
  - Step-by-step visual guide for connecting guitars using 1/4" to 3.5mm adapters, splitters, USB OTG cables, or USB Audio Interfaces

- **Custom Theme Skinning**:
  - Real-time skin switcher: Modern, TubeAmp, Classic, Analog, Hybrid, and Adwaita
